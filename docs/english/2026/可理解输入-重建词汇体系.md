# 背了又忘？用"可理解输入"重建你的词汇体系

如果你背单词的状态是"今天背、明天忘、后天重新背"，那大概率不是你记性差，而是**这个词从来没有真正进入过你的语言系统**。

## 为什么孤立背单词留不住

一个单词要真正被记住，需要在大脑里和**已有的经验**建立连接。单词表给的是"符号—中文释义"的对应关系，这条线太细，一扯就断。

真正牢固的记忆长这样：你在某个具体场景里见过它，知道它跟谁搭配、在什么语气下出现、换成别的词会哪里不自然。

## i+1：选对材料比努力更重要

可理解输入的核心是 **i+1**：

- **i** 是你现在的水平
- **+1** 是只比现在难一点点

判断标准很简单：**一页里不认识的单词不超过 5%**。超过了，你不是在学英语，是在查字典。

## 让单词自己回来找你

比起"背"，更有效的是"复现"：

1. 同一主题连续读 3～5 篇材料，核心词会自然重复出现
2. 遇到生词先猜，再查，最后记**搭配**而不是记释义
3. 隔天回看一遍，只留下仍然陌生的词

一句话总结：**别追着单词跑，让单词在不同的语境里反复撞见你。**

## 小结

| 做法 | 效果 |
| --- | --- |
| 单词表机械背诵 | 短期记住，快速遗忘 |
| 超出水平太多的材料 | 挫败感强，留存率低 |
| i+1 + 主题化复现 | 慢，但留得住 |

先让材料变简单，再让重复变自然。
