# 还手之后

突然想到一个事。

有人打了我，我还回去了。但打完之后，并没有觉得得到了什么补偿。

后来想了想，大概是因为——我真正想要的，其实不是"打回去"，而是"没被打过"。

还手这件事，最多只能让对方也疼一下，但已经落在我身上的那一下，是补不回来的。就像东西碎了，你把碎片拼回去，裂痕还在。所以打完之后，身体可能松了一点，但心里那个"凭什么"的感觉，还在原地。

而且说实话，还手很多时候只是本能反应，不是真的在"讨债"。你心里可能更多是委屈、是愤怒、是不甘心，而不是真的想伤害对方。所以当你真的去伤害对方时，你的本能在抵抗，会觉得空、会觉得累，甚至有点恶心。

这其实说明你的底色是好的。

但底色好，不代表就要一直忍着。真正让自己舒服的方式，可能不是以牙还牙，而是把精力收回来，放在自己身上。

有些伤口补不回来，但日子可以往前过。
